# 🎬 Rayliziie Nime

Website streaming anime sederhana dengan tampilan modern, terintegrasi dengan **Unofficial Otakudesu API**.

## ✨ Fitur

- 🏠 **Beranda** — Tampilkan anime terbaru
- 🔥 **Ongoing** — Anime yang masih tayang
- ✅ **Completed** — Anime yang sudah selesai
- 📅 **Jadwal** — Jadwal rilis anime
- 🔍 **Pencarian** — Cari anime berdasarkan judul
- 📺 **Detail Anime** — Sinopsis, rating, genre, daftar episode

## 🚀 Teknologi

- HTML5 + CSS3
- JavaScript (ES6+)
- [Unofficial Otakudesu API](https://github.com/rakarmp/unofficial-otakudesu-api)

## 🛠️ Cara Menjalankan

1. Clone repository ini
2. Buka `index.html` di browser
3. Atau gunakan Live Server di VS Code
